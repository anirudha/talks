2026 reality check
Agents are everywhere.
And they're breaking everywhere.

Customer support. Code generation. Data pipelines. The agents that ship production traffic now sit in your hottest paths — and you've never had less visibility into a workload.

The core problem

Traditional APM treats an agent as a black box.

You see one span — /invoke, 14 seconds, 200 OK. Inside that span: twelve LLM calls, four tools, three retries, and a hallucinated database query. Your dashboard says it succeeded. Your user disagrees.

What APM shows
A single fat span
Latency, throughput, error rate at the request boundary. Useful for services. Useless for agents.
What's actually happening
Multi-step reasoning
Plan, call, read, call again, retry, branch. Tool calls. Sub-agents. State you can't see in a single duration metric.
The gap
No semantic vocabulary
No standard for input/output, model, tokens, tool inputs. So even when you capture data, no one tool can query across it.
The failure modes you can't see

Three ways your agent is already failing in prod.

Failure 01
Hallucinates mid-task
Returns a confident, well-formatted, completely wrong answer. The trace looks healthy. The output is fiction. No alert fires.
Failure 02
Silently degrades
Quality drops 20% after a model swap or prompt edit. Latency unchanged. Error rate unchanged. You find out from a user complaint a week later.
Failure 03
Drifts off the path
Same input, different tool sequence. Token cost doubles. The "right answer" still arrives — by the wrong route — and you only notice on the AWS bill.

Metrics aggregation, on demand

PPL across every agent span.

Token spend by model, tool failure rate by agent, p99 latency by sub-agent — composed live, not pre-built. 

// Per-agent token cost in the last hour
source = otel-traces
| where spanKind = "INTERNAL" and attributes.gen_ai.agent.id is not null
| stats
    sum(attributes.gen_ai.usage.input_tokens)  as in_tokens,
    sum(attributes.gen_ai.usage.output_tokens) as out_tokens,
    count()                                     as calls
  by attributes.gen_ai.agent.id, attributes.gen_ai.request.model
| eval est_cost_usd = (in_tokens * 0.000003) + (out_tokens * 0.000015)
| sort -est_cost_usd
| head 10
